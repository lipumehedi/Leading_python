
# Python Contact Book

A command-line contact management application.

## Features
- Add and list contacts
- Search by name or phone
- Edit contact details
- Delete contacts
- Persist data in JSON

## Run
```bash
python main.py
```

## Data
Contacts are stored in `contacts.json`.
Keep personal contact information out of public repositories.

## Concepts
Functions, JSON, pathlib, lists, dictionaries, CRUD operations.
