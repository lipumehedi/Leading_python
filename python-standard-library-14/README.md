# Python Standard Library — 14 Practical Examples

A collection of 14 practical Python examples covering useful Python concepts and standard library modules. This project is designed for learning, practicing, and building a strong foundation in Python programming.

## 📚 Topics Covered

| No. | Topic | Concepts |
|---:|---|---|
| 01 | Module Import | `import`, `from ... import`, `math` |
| 02 | Default Values and None | Default parameters, `None` |
| 03 | Lists and Dictionaries | Lists, dictionaries, `enumerate()`, `pop()` |
| 04 | Dataclasses and Objects | Classes, `@dataclass`, `asdict()` |
| 05 | Error Handling | `try`, `except`, `raise`, custom exceptions |
| 06 | F-Strings and Formatting | String formatting, number formatting |
| 07 | List Comprehension | List comprehension, generators, `sum()` |
| 08 | Sorting and Lambda | `sorted()`, `key`, `lambda` |
| 09 | File Read and Write | `open()`, `with`, `os` |
| 10 | JSON Data | `json.dump()`, `json.load()`, serialization |
| 11 | Date and Time | `datetime`, `strptime()`, `strftime()` |
| 12 | Command-Line Arguments | `argparse`, command-line inputs |
| 13 | Main Entry Point | `if __name__ == "__main__":` |
| 14 | Python Shortcuts | Conditional expressions, `or`, `continue` |

## 🎯 Learning Objectives

- Understand how to import and use Python modules.
- Work with lists, dictionaries, classes, and dataclasses.
- Handle errors using exceptions.
- Format strings and numbers effectively.
- Read and write files using Python.
- Store and retrieve data using JSON.
- Process dates and validate date inputs.
- Build command-line interfaces using `argparse`.
- Understand Python program execution and reusable code.
- Practice writing clean and readable Python code.
