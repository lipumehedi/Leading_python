
# Python Student Grade Calculator

A program to calculate student marks and grades.

## Features
- Three-subject marks input
- Marks validation
- Total and average calculation
- Grade assignment

## Run
```bash
python main.py
```

## Grade Scale
A+: 80+, A: 70+, A-: 60+, B: 50+,
C: 40+, D: 33+, F: below 33.

## Concepts
Functions, loops, lists, arithmetic and validation.
